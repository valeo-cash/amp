# AMP IETF Internet-Draft

`draft-valeo-amp-channel-00` -- Autonomous Machine Payments: Persistent Financial State Channels for Machine-to-Machine Transactions.

## Build

Install xml2rfc:

```bash
pip install xml2rfc
```

Generate HTML and plaintext renderings:

```bash
make
```

## Validate

Check for nits before submission:

```bash
idnits draft-valeo-amp-channel-00.txt
```

## Submit

Upload `draft-valeo-amp-channel-00.xml` at https://datatracker.ietf.org/submit/

The IETF tools will validate and generate official renderings.
